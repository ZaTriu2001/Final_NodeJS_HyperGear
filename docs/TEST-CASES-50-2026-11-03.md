# HyperGear — 50 test case nghiệm thu

Ngày chạy: 03/11/2026. 50 case dưới đây là **case nghiệm thu**, được đối chiếu với nhiều assertion trong các bộ tự động, không phải 50 file hoặc 50 test function độc lập.

Kết quả: **44 Đạt, 3 Lệch đề, 1 Chưa nghiệm thu (Google), 2 Không triển khai (coupon)**. Ba case lệch đề vẫn đúng quy tắc nhóm đã chốt; vì mục tiêu là chấm theo đề nên không ghi chúng là PASS theo PDF. Case Google/coupon không được cộng vào số test đã chạy thành công.

Môi trường: Node24 + MongoDB replica set riêng cho integration/logic; Redis thật native. Elasticsearch, hai catalog/gateway, Nginx và Chromium desktop/mobile chạy Docker CI. Gemini thật dùng key server-side trên localhost; test tự động cô lập cố ý bỏ key để không tốn quota. Các test tài khoản/đơn/race dùng DB riêng, không phá dữ liệu demo. Postman tạo dữ liệu thử trong DB demo.

## Những lỗi đã phát hiện và sửa

1. **Logic trạng thái đơn:** request thiếu status trên đơn delivered từng được chấp nhận vì so sánh undefined với undefined. Đã whitelist status và chặn trạng thái cuối. L01 thất bại trước sửa, đạt sau sửa; kiểm tra DB status/history không đổi.
2. **Logic PC compatibility:** so sánh số với undefined tạo NaN nên các điều kiện `<`/`>` không phát hiện thiếu thông số. Đã kiểm tra bắt buộc kiểu/giá trị chuỗi, số dương, danh sách và duy nhất mỗi role trước khi so tương thích. L05 thất bại trước sửa, đạt sau sửa với7field thiếu.
3. **Search:** fuzzy ngắn làm man hinh khớp36sản phẩm thay vì8. Đã exact-first, chỉ fuzzy khi không có exact; CI ES kiểm tra cả rename/archive.
4. **UI QA:** nhãn filter biểu đồ không được định danh rõ cho automation; đã thêm aria-label. Browser admin desktop/mobile đạt sau sửa. Native demo thêm --production để tránh module React cũ do cache HMR; production hiển thị đã được kiểm tra.

Không kết luận phần mềm không còn mọi lỗi. Chưa có kiểm thử tải lớn, Safari/iPhone thật, thanh toán thật hoặc thông số hãng/BIOS/connector cho PC thương mại. Lịch sử Git hiện chỉ thấy một tác giả trong checkout, không thay bằng chứng đóng góp hai người.

## Lệnh chạy lại

```sh
npm run lint
npm test
npm run build
npm run test:integration
npm run test:logic
REDIS_URL=redis://127.0.0.1:6379 ELASTICSEARCH_URL=http://127.0.0.1:9200 npm run test:m3-m4
npm run test:smoke
npm run test:messaging
npm run test:browser
node scripts/scaling-smoke.mjs
```

Các lệnh smoke/messaging/browser/scaling cần Docker stack đang chạy; không gọi scaling trên native một gateway rồi kỳ vọng hai instance. Nếu thiếu ES/Redis, test tương ứng có thể SKIP; báo cáo local không được tự cộng là đã PASS. CI dùng cả hai dịch vụ thật.
